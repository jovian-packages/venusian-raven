## About Venusian Raven

> **Note:** This repository contains the Raven toolkit driver for the Venusian framework. If you want to build an application using Venusian, visit the main [Venusian skeleton repository](https://github.com/VenusianPHP/venusian).

Venusian Raven is the Raven toolkit driver for Venusian Topside: it starts Raven, opens its windows, builds their menu bars and turns Topside's views into Raven widgets through [ext-raven](https://github.com/php-io-extensions/raven), all in the Laravel-like syntax you already know.

Raven is a retained-mode GUI toolkit in C with its own Vulkan renderer and native Cocoa, X11 and Wayland windows. Want an app that looks the same everywhere and draws every pixel itself? Write your view once with Topside and Venusian Raven gives you buttons, text inputs and areas, tables, lists and trees, split and tab views, dialogs, the clipboard, and a menu bar with shortcuts and enabled states, themed Dark, Light, Glass or High Contrast, or from your own theme file.

Linux and macOS. Raven loads the Vulkan loader itself (MoltenVK on macOS). Prefer a native toolkit? Reach for `jovian/venusian-qt`, `jovian/venusian-gtk` or `jovian/venusian-appkit` and keep the same views.

> **Built with AI assistance.** This package was developed LLM-assisted — not vibe-coded. Generated code was deliberately prompted and reviewed by a professional software engineer. See [AI-assisted development](#ai-assisted-development).
